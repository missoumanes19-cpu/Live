# ANES TV

تم تحديث واجهة التطبيق وإضافة صفحة **السيرفر** قبل قسم البث المباشر.

## أنواع الاتصال
- Xtream Codes: عنوان السيرفر + اسم المستخدم + كلمة المرور (يعرض قنوات Live).
- ملف M3U/M3U8: اختيار ملف من الجهاز.
- رابط M3U: جلب القائمة من رابط مباشر.
- GitHub Online: رابط `raw.githubusercontent.com` لملف M3U مستضاف في مستودع GitHub عام، مع أزرار الاتصال وإعادة التحميل.

## التشغيل
1. افتح المشروع في مجلد `iptv`.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter run` أو ابنِ APK عبر `flutter build apk`.

## ملاحظات مهمة
- GitHub ليس مزود بث IPTV بحد ذاته؛ التطبيق يقرأ ملف M3U من GitHub Raw. يجب أن يحتوي الملف على روابط بث صالحة ومصرّح باستخدامها.
- بيانات Xtream تُحفظ محلياً في Hive على الجهاز لتسهيل إعادة الاتصال. لا تشارك ملف بيانات التطبيق أو جهازك مع الآخرين.
- ملفات M3U المحلية لا يعاد تحميلها تلقائياً بعد إغلاق التطبيق؛ اختر الملف مرة أخرى عند الحاجة.
- الأرشيف المصدر كان يحتوي ملفات `lib/` وملف dependencies فقط ولم يتضمن مجلدات Android/iOS الأصلية. أضيف `pubspec.yaml`، لكن يلزم إنشاء هيكل منصة Flutter (مثلاً `flutter create .`) داخل نسخة عمل مناسبة قبل بناء APK إذا لم يكن موجوداً في مشروعك الأصلي الكامل.


## Xtream Codes الكامل
بعد تسجيل الدخول من صفحة السيرفر، يوفر التطبيق أقسام البث المباشر والأفلام والمسلسلات. تُحمّل قوائم الأقسام من واجهة Xtream API، وتُعرض التصنيفات حسب أسماء الفئات. الضغط على فيلم يفتح المشغل، والضغط على مسلسل يجلب بيانات الحلقات والمواسم من `get_series_info` ثم يتيح تشغيل الحلقة المختارة.

ملاحظة: توافق روابط التشغيل وامتداداتها يعتمد على إعدادات مزود الخدمة؛ بعض الخوادم تستخدم `ts` أو `m3u8` للبث المباشر، وامتدادات مختلفة للأفلام والحلقات. استخدم فقط بيانات وخدمات لديك تصريح بالوصول إليها.
